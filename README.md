Header & Badge: Identitas proyek, status pengembangan, versi teknologi (React 19, Vite 6, Tailwind CSS v4, TanStack Table v8).
Latar Belakang & Tujuan: Dashboard monitoring performa operasional, koordinasi agenda, dan evaluasi data kinerja untuk unit SSGS Telkom Regional 3.
Fitur Utama:
📌 Executive Overview (/dashboard): Tracking hierarki agenda, isu Witel, aktivitas UIC, dan ekspor CSV.
📋 EDK Monitoring (/edk-monitoring): Evaluasi data order & abonemen, multi-mode view (AM, Periode, Segmen, Flagging), filtering dinamis, dan TanStack React Table.
🧭 Analisis Kuadran (/kuadran/:view): Grid matriks 4-kuadran (Moving, Witel, Telda, Segment), fitur upload berkas, dan share link.
🤝 Support Needed Tracker (/support-needed): Status eskalasi dukungan dan rekapitulasi lintas unit.
Teknologi & Dependensi: Daftar framework, visualisasi (Recharts), ikon (Lucide React), tabel, dan utilitas ekspor.
Struktur Direktori: Pemetaan folder dan file proyek secara lengkap.
Panduan Instalasi & Menjalankan: Langkah-langkah npm install, npm run dev, serta npm run build.
Panduan Penggunaan Fitur: Navigasi sidebar collapsible, filter tabel, dan download laporan.
